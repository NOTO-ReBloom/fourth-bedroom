# CHANGELOG — Production 1.7

## Balance

- 大規模調査 `a406` の必要発見数を 8/10 から 7/10へ調整
- 大規模調査 `a503` の必要発見数を 9/11 から 8/11へ調整
- 操作のない長い場面へ32か所の場面カードを追加
- 文字表示速度の初期値を15msから12msへ調整
- AUTO待ち時間の初期値を1150msから1050msへ調整

## Assistance

- 観察補助3モードを追加
- 調査ヒントは未発見ポイントを一か所だけ強調
- パズルは二度目の誤答から見直す項目を提示
- 物語重視モードでは一項目だけ候補を反映可能

## QA Metrics

- ノード訪問数
- 選択肢の選択回数
- 調査時間とヒント使用
- パズル試行回数
- ゲームオーバー別回数
- 章別滞在時間
- JSON書き出し

## Input / Accessibility

- 調査ポイントの最小タッチ領域を44pxへ統一
- 小さかった4ポイントのデータ領域を拡大
- 数字キー1〜9で選択肢操作
- Gキーで調査ヒント
- モバイル設定・プレイ記録画面を調整

## Save

- 保存名前空間を `production-v17` へ更新
- `production-v16` のAUTO／手動3枠を自動コピー
- 旧保存は削除せず保持
