# 演出・音響設計 Final Candidate 2.2

## 1. 画面遷移
場面が変わるたびに同じ暗転を使わず、物語上の層に合わせて遷移方法を変える。

- **現代**：暗部が左右から閉じる静かなフェード
- **1888〜1948年の絵画・資料層**：筆の帯が画面を横切るペイント遷移
- **死に戻り・層移動**：青と赤の位置がずれる記憶遷移
- **火災・過熱**：褐色と黒が画面を覆う熱遷移

遷移は情報を隠す装飾ではなく、「今どの層へ移ったか」を言葉なしで伝える役割を持つ。

## 2. カメラ距離
背景や人物画像そのものを増やさず、場面の意味に応じて画面の距離を変える。

- **close**：危険、恐怖、煙、崩壊
- **detail**：資料、走査、機器、比較
- **uneasy**：記憶、暗転、鍵穴、空白
- **wide**：外景、夜明け、展示室

## 3. 人物演技
台詞が切り替わる瞬間、話者だけがわずかに前へ出て光を取り戻す。聞き手は完全に消さず、彩度と明度を落とす。

別人に見える表情差分を乱用せず、同一人物の距離、呼吸、姿勢、光量で感情を表す。

## 4. 音楽
完成BGMの代用として大きな旋律を鳴らさず、時代ごとに3音の持続音を低音量で配置する。

- modern
- arles
- saint
- marta
- forgery
- final
- danger
- memory

環境音と競合しないよう、初期音量は28%。設定から独立して調整できる。

## 5. AUTO
固定秒数ではなく、以下を合算して間を決める。

- 文字数
- 句点、疑問符、感嘆符
- 読点、省略記号
- 改行
- 会話／内心／文書の種別
- 人物固有のdelivery
- 危険場面の追加余韻

## 6. プレイフィール
- 選択肢を同時に出さず、上から短い間隔で立ち上げる
- 保存成功を画面右下へ短く表示する
- ↑キーで直前文章を一時確認できる
- 演出軽減時は遷移・人物アニメーションを停止する
