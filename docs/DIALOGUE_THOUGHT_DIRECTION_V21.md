# Dialogue / Thought Direction — Final Candidate 2.1

## 採用した表示規則

### 発言
- 画面下部のADVウィンドウを使用する。
- 名前欄をウィンドウ上端へ独立表示する。
- 発話者の人物画だけを明るくし、聞き手は一段暗くする。
- 台詞には括弧を付けない。名前欄そのものが発言であることを示す。

### 澄の心の声
- 名前欄を表示しない。
- 「内心」「POV」等の説明ラベルを表示しない。
- 外枠を消した細いグラデーション領域へ表示する。
- 人物画をわずかに沈ませ、画面全体を澄の意識へ寄せる。
- 日本語で読みにくい斜体は使わず、余白・字間・色温度で区別する。

### 澄が見聞きしたこと
- 名前欄を表示しない。
- 心の声より中立的な細い文章帯を使用する。
- 推測を混ぜず、現在の感覚・動作・位置だけを書く。

### 文書／システム
- 人物会話とは別の紙・機器系の配色と書体を使う。

## 調査から得た判断

Ren'Pyの公式文書では、話者名を伴う台詞と、話者名のないナレーションが別形式として扱われ、名前を `None` にした場合は名前表示が省略されます。また、キャラクターごとに台詞ウィンドウの外観を変更できます。

Naninovelの公式文書でも、通常のDialogue Printerは名前ラベルを持ち、用途に応じてFullscreen、Chat、Bubbleなど別のプリンターへ切り替える設計です。つまり、文章の種類を文字ラベルで説明するのではなく、表示器そのものを変えることが一般的です。

本作では、ミステリーADVとして背景と人物を見せ続ける必要があるため、NVL型の全面文章表示ではなく、ADV型の発言欄と、話者なしの心中／観察欄を切り替える方式を採用しました。
