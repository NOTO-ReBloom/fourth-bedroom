# Narrative Direction 1.8

## 採用形式

『第四の寝室』は、水瀬澄の限定視点だけで進むシネマティックADVとする。

画面へ表示する文章は、原則として次の四種類に限定する。

1. `dialogue` — 登場人物が実際に発した言葉
2. `inner` — 澄がその瞬間に見た・聞いた・感じたこと、または直後の判断
3. `document` — 画面、手紙、目録、報告書など、作中に実在する文字
4. `system` — 調査・照合など、プレイヤー操作を案内する最小限の表示

客観的な地の文、登場人物の内面の断定、澄が見ていない場所の説明は使用しない。

## 一画面の原則

- 一クリックにつき、一つの発話または一つの知覚を表示する。
- 会話と動作説明を同じ文章へ混在させない。
- 通常の一セグメントは110字以内とする。
- 表情・姿勢・移動は、可能な限り人物画、背景、カメラ、効果音で示す。
- 文章で動作を示す必要がある場合も、澄が見た事実として記述する。
- 推測は「そう見える」「かもしれない」とし、他者の心理を確定しない。

## 死に戻りとの関係

同じ背景でも、周回前後で澄の知覚文を変える。

初回：

> 防火扉が動き出す。

復帰後：

> 閉まり切るまで九十秒。解除しても、また閉じる。

世界が変わったのではなく、澄の記憶によって同じ物の意味が変化したことを示す。

## 表示エンジン

旧版は1ノードにつき1文章だった。1.8では、ノードの進行条件を維持したまま、各ノードが複数の`script`セグメントを持つ。

例：

1. クレールの発話
2. 澄が見た表情
3. 澄の内心
4. 澄の返答

選択肢・調査・パズルは、最後のセグメントを読み終えた後にだけ表示される。

AUTO、既読SKIP、会話ログ、途中セーブはセグメント単位で動作する。ノード途中で保存した場合も、同じ発話位置から再開する。

## 禁止事項

- 「地の文」を話者として表示する
- 会話欄の中へ「○○は振り返った」などの舞台指示を入れる
- 澄の内心で「澄は」「澄が」と第三者のように呼ぶ
- 澄が知らない史実や犯人の意図を先に説明する
- 手掛かりを情緒的な比喩だけで提示する
- 死亡原因を死亡後に初めて追加する
