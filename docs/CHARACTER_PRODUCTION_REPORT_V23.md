# 人物画最終制作レポート — 2.3

## 制作工程

1. Final Candidate 2.2の人物別マスター6枚を人物単位で確認。
2. 矩形状の旧アルファマットを廃止。
3. 単一人物のシルエットを抽出し、最大連結成分だけを保持。
4. 輪郭をフェザー処理し、背景色の縁取りを除去。
5. 顔領域を固定し、表情状態ごとに局所変形。
6. 人物ごとの顔・髪・服装・姿勢を変えずに色調を調整。
7. 6人物×13表情＝78枚を書き出し。
8. 実装側の感情状態から個別画像へ切り替える方式へ変更。
9. PC、モバイル、全5ルート、GitHub Pages相対パスを検証。

## 画像仕様

- 形式：WebP RGBA
- サイズ：720×960
- 背景：透明
- ファイル構造：`site/assets/characters/expressions/<character>/<mood>.webp`
- QAコンタクトシート：`tests/character_v23_<character>_qa.jpg`
- QAコンタクトシートはゲーム本体から未参照

## 再現性

`scripts/generate-character-variants.py`で同じファイル構成を再生成できる。`scripts/validate-character-assets.py`でサイズ、透明性、連結成分、重複、顔構造と差分量を再検証できる。

## 制約

人物の基準造形はFinal Candidate 2.2の個別人物マスターを継承している。2.3では、複数人物を一枚にした画像をゲームへ直接使用せず、人物単位の透過素材と感情差分へ再制作した。史実人物は新規の架空顔を作らず、自画像を別系列で扱う。
